# IT-105: Behavior report lists behaviors as a table

**Type:** Story · **Owner:** Jonas (FE: reports) · **Points:** 3 · **Reviewer:** Mei

## Story
As a developer reading the "Show Behaviors" report, I want the behaviors in a table with the conditions and
the outcome in separate columns, so that I can scan a long function quickly.

## Acceptance criteria (DRAFT: finish in `/refinement IT-105`)
- The *Behaviors* section of the report is a markdown table with columns `#`, `When`, `Then`, `Line`
- A behavior with no conditions shows `Always` in *When*
- _Open: what about very long conditions? Conditions that contain characters that mean something in markdown? Functions with 0 behaviors?_
