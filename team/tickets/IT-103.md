# IT-103: Status bar shows mismatch count for the active file

**Type:** Story · **Owner:** Mei (FE: editor) · **Points:** 3 · **Reviewer:** Jonas

## Story
As a developer, I want the status bar to show how many possible mismatches are in the file I'm editing,
so that I notice them without scrolling through the whole file.

## Acceptance criteria (DRAFT: finish in `/refinement IT-103`)
- When the active editor is a JS or TS file with possible mismatches, the status bar shows e.g. `⚠ 2 intent mismatches`
- Clicking it opens the Problems panel
- _Open: what shows when there are 0? When the active editor isn't JS or TS? When `intentTests.mismatchWarnings` is off? Does it update while typing, or on save?_
