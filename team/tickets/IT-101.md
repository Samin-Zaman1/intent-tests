# IT-101: `check` and `diff` can print JSON for CI

**Type:** Story · **Owner:** Rafi (BE) · **Points:** 5 · **Reviewer:** Mei

## Story
As a team running Intent Tests in CI, I want `intent-tests check` and `intent-tests diff` to print
machine-readable JSON, so that our pipeline can fail the build and comment on PRs without parsing markdown.

## Acceptance criteria (DRAFT: finish in `/refinement IT-101`)
- Given `--json`, `intent-tests check` prints a JSON object instead of markdown, and the exit code is unchanged (0 when the plan is met, 1 when it isn't)
- Given `--json`, `intent-tests diff` prints a JSON object
- _Open: what happens on errors (missing plan file, not a git repo) with `--json`? Is the JSON shape documented? Does `--json` work before and after other flags?_
